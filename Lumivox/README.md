# Lumivox

Meu primeiro aplicativo: um app Android de acessibilidade (leitura de texto em voz alta, Braille, calculadora, biblioteca local), feito em HTML/CSS/JS dentro de um WebView.

- Código: `app/`
- Como gerar o APK: `README_GERAR_APK_DEFINITIVO.md`
- O workflow `.github/workflows/build-lumivox-apk.yml` só roda quando algo em `Lumivox/` muda ou quando é disparado manualmente (aba Actions > Run workflow).
