LUMIVOX - OPCAO ONLINE PELO CODEMAGIC

Este pacote tambem contem codemagic.yaml.

PASSO A PASSO RESUMIDO:
1. Envie o projeto para um repositorio GitHub, GitLab ou Bitbucket.
2. Entre no Codemagic.
3. Conecte o repositorio.
4. Selecione o workflow android-debug.
5. Execute o build.
6. Baixe o APK em Artifacts.

Use esta opcao se preferir uma interface mais visual do que GitHub Actions.
