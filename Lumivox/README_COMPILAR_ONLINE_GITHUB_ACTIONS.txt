LUMIVOX - GERAR APK ONLINE PELO GITHUB ACTIONS

Este pacote ja contem o arquivo:
.github/workflows/build-lumivox-apk.yml

PASSO A PASSO:
1. Crie uma conta no GitHub, se ainda nao tiver.
2. Crie um repositorio novo chamado lumivox-android.
3. Envie todos os arquivos desta pasta para o repositorio.
4. No GitHub, abra a aba Actions.
5. Clique em Gerar APK Lumivox.
6. Clique em Run workflow.
7. Aguarde a compilacao terminar.
8. Abra a execucao concluida.
9. No final da pagina, em Artifacts, baixe Lumivox-APK-debug.
10. Dentro do ZIP baixado, estara o arquivo app-debug.apk.
11. Copie o APK para o Xiaomi/Android e instale como aplicativo de teste.

OBSERVACOES:
- O APK gerado sera DEBUG, indicado para teste.
- Para publicar em loja, sera necessario gerar APK/AAB RELEASE assinado.
- Se o celular bloquear a instalacao, ative "Instalar apps desconhecidos" apenas para o gerenciador de arquivos ou navegador que estiver usando.
- Depois de instalar, desative novamente essa permissao por seguranca.
